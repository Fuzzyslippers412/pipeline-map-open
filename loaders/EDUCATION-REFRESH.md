# Education tables and CPS Table 11

Run `python3 loaders/refresh_education.py` from the project root. Python uses only its standard library. The online AAMC reader also needs Poppler's `pdftotext`. All publisher documents are downloaded into memory or temporary files, and only the derived aggregates enter the repository.

The command attempts a fresh retrieval for all three publishers. If an original is unavailable, it clearly identifies the fallback on stderr and retains the previous verification date. Use `--strict-network` to reject a partial refresh and retain existing outputs. Use `--offline` to reproduce the published data without the network. All selected sources must finish validation before any output is replaced.

- **AAMC.** The CSV in `loaders/reviewed/aamc-cells.csv` records the audited numerator and denominator from the publisher's PDF. Its 2016 A-9 prints women before men, whereas later A-9 editions print men first. For an annual update, inspect the FACTS catalogue for a new *matriculants × race × gender* table. Register the exact edition, jurisdiction, category, denominator and checked cells. A table listing race alone cannot extend this series. A-9 excludes unreported genders. A-12's All section includes them. Keep the two segments separate.
- **ABA.** The loader downloads the public 509 **JD Enrollment and Ethnicity** workbook for each year, sums Black men and women separately, and divides each count by the sum of the entire JD1 cohort. It checks year, duplicate schools, column labels and bounds. The JD1 cohort includes all first-year students, including continuing students. The narrower “entering class” totals in the ABA news release use a different denominator. To include a newly released year, run `python3 loaders/refresh_education.py --source aba --aba-through YYYY --strict-network`. Compare the aggregate and number of schools against the publisher's workbook. Record the reviewed aggregate in the CSV, review that year's reporting instructions, and update the default final year. From 2024 onward, race categories include U.S. nonresidents previously recorded separately.
- **BLS.** The loader checks the annual CPS Table 11 column structure and survey year, and records it as a contextual source only. The percent women and the percent Black columns do not supply their intersection. Publishing a Black male or Black female estimate from Table 11 alone is a validation error.

Build from the committed aggregate JSON, not a live request. Compare the release diff for series IDs and denominators when a publisher changes its definition. The full AAMC/ABA documents are not redistributed.
